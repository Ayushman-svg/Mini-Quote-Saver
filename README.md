Mini Quote Saver

A simple web app that allows users to save, view, and delete their favorite quotes using localStorage. All quotes remain saved even after refreshing or closing the browser.

Features:

Add new quotes

Display all saved quotes

Delete any quote

Automatically saves data in localStorage

Clean and simple user interface

What this project teaches:

How to store and retrieve data from localStorage

How to convert arrays to JSON and back

Basic DOM manipulation

Rendering dynamic lists

Simple Create and Delete operations in JavaScript

Project Structure:
index.html – Main HTML structure
style.css – All styling and UI design
script.js – JavaScript logic for saving, loading, and deleting quotes

How to Use:

Type a quote in the input box

Click “Add Quote”

Your quote will appear in the list

Click “Delete” to remove any saved quote

No installation needed. Just open index.html in any browser.
